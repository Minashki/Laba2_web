Лабораторная работа №2 — Уязвимости веб-приложения на Python
1. Цель работыСоздать локальное веб-приложение на Python, продемонстрировать две уязвимости веб-безопасности, проверить их работу с помощью тестовых скриптов и исправить обнаруженные проблемы.
2. Используемые средства
	Python 3
	http.server — запуск HTTP-сервера
	sqlite3 — работа с базой данных
	urllib.parse и urllib.request — обработка URL и отправка тестовых запросов
	pathlib — работа с путями к файлам
Используются стандартные модули Python, поэтому дополнительные библиотеки устанавливать не требуется.
3. Реализованные уязвимости
SQL Injection
В уязвимой версии пользовательский ввод напрямую подставляется в SQL-запрос. Это позволяет изменить условие поиска и получить записи, которые не должны были возвращаться обычным запросом.
Исправление: параметризованный SQL-запрос с использованием плейсхолдера ?.
Path Traversal
В уязвимой версии приложение не проверяет, находится ли запрашиваемый файл внутри разрешённой директории. Специально сформированный путь может позволить прочитать файл за её пределами.
Исправление: нормализация пути и проверка, что итоговый путь остаётся внутри разрешённой директории.
4. Состав проекта
app_vulnerable.py — версия приложения с учебными уязвимостями.
app_fixed.py — версия приложения с исправлениями.
test_sql_injection.py — тест SQL Injection.
test_path_traversal.py — тест Path Traversal.
fixes.patch — сравнение изменений между версиями.
public/info.txt — публичный тестовый файл.
secret.txt — тестовый файл за пределами публичной директории.
users.db — база данных пользователей, создаваемая приложением.
5. Запуск и проверка
Перейти в каталог проекта:
	cd ~/lab2
Запустить уязвимую версию:
	python3 app_vulnerable.py
В другом терминале выполнить тесты:
	python3 test_sql_injection.py 
	python3 test_path_traversal.py
Затем остановить сервер сочетанием Ctrl+C, запустить исправленную версию:
	python3 app_fixed.py
Повторно выполнить оба теста. В исправленной версии SQL-инъекция не должна возвращать всех пользователей, а попытка выйти за пределы разрешённой директории должна блокироваться.
6. Результат работы
Создано локальное веб-приложение, продемонстрированы SQL Injection и Path Traversal, подготовлены тестовые скрипты и исправленная версия приложения. Результаты проверяются сравнением ответов уязвимой и исправленной версий.Приложение предназначено для учебных испытаний в локальной среде.
